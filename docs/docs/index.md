# transLAST documentation!

## Description

Traditional methods for detecting LINE-1 retroelement sequences in genomic samples typically rely on pattern matching and sequence alignment. These approaches, however, are limited in their ability to identify novel or divergent LINE-1 sequences and to distinguish between segmental duplications and the actual number of LINE-1 copies. The objective of this study was to develop an alignment-free approach for analyzing LINE-1 retroelements.
