# Archive

Retired code, kept for its history. Nothing here is called by the pipeline, the
tests or any manuscript item, and nothing here is maintained: scripts are kept
verbatim, so their relative paths and defaults reflect the layout they were
written for and may no longer run.

Paths mirror the original location (`archive/scripts/draft/x.sh` was
`scripts/draft/x.sh`). Every file was moved, not rewritten, at the commit that
added this directory; `git log --follow archive/<path>` shows its full history,
and all of it is also reachable at tag `v1.0.0`. The full list, with the last
commit before the move, is in `docs/guides/archive_index.md`.

Code that is unreported but still informative stays in place and is listed under
"Not behind any reported result" in `docs/guides/manuscript_provenance.md`.
`scripts/slurm/legacy/` is also an archive, frozen in place because some of its
files are cited for reported results.
